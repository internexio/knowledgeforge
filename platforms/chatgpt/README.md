# KnowledgeForge — ChatGPT Projects

> **Experimental:** This variant has not received the same validation coverage as the Claude variants.

Pre-compiled output for ChatGPT Projects. Generated by `compiler/kf-compile.py --target chatgpt`.

## Install

### 1. Project Instructions

Open your ChatGPT Project, go to **Settings > Instructions**, and paste only the full contents of the generated `kf-chatgpt-instructions.md` routing kernel. Do not paste the detailed module files into the Instructions field.

The compiler enforces a 6,500-character operating target and ChatGPT's 8,000-character hard limit. Compilation fails if either binding budget is missing or invalid, or if the kernel exceeds the operating target.

### 2. Knowledge Files

Upload all files from the `knowledge/` directory to the project's **Knowledge** section.

These project sources are retrieved reference context, not guaranteed always-on instructions. The routing kernel names the required mode files and directs ChatGPT to retrieve the appropriate source before applying a mode. Retrieved sources never outrank system, developer, project, or user instructions.

Before re-uploading after a recompile, delete the existing knowledge files first — ChatGPT does not deduplicate by filename.

> **File limit:** Custom GPTs have a 20-file cap; ChatGPT Projects is more permissive. If you hit a limit, prioritize `knowledge/01`–`knowledge/11` (the mode specs) over the infrastructure modules `12`–`25`.

## Degraded Fallback

If ChatGPT cannot retrieve a required mode file, the kernel requires it to identify the missing filename, mark the response as degraded, use only the routing kernel and general reasoning, lower confidence, and avoid claiming mode-specific guarantees. Restore or re-upload the missing source when that prevents a reliable answer.

## Update Flow

When modules in `knowledgeforge-core` change:

```bash
cd ~/Scripts/knowledgeforge-core
python3 compiler/kf-compile.py --target chatgpt --output platforms/chatgpt
```

Then re-paste the instructions file and re-upload any changed knowledge files.
