# KnowledgeForge — Codex CLI

Pre-compiled output for OpenAI Codex CLI. Generated by `compiler/kf-compile.py --target codex`.

## Install

Copy `AGENTS.md` to your project root:

```bash
cp ~/Scripts/knowledgeforge-core/platforms/codex/AGENTS.md /path/to/your/project/AGENTS.md
```

Codex CLI reads `AGENTS.md` automatically when present at the project root — equivalent to how Claude Code reads `CLAUDE.md`.

## Update Flow

When modules in `knowledgeforge-core` change:

```bash
cd ~/Scripts/knowledgeforge-core
python3 compiler/kf-compile.py --target codex --output platforms/codex
```

Then copy the updated `AGENTS.md` to any projects using it.

## Source

- Platform binding: `platform-bindings/codex.yaml`
- Compiled from: `modules/00_orchestrator.md`
- CC-specific sections (`## CC Skill`, `## CC Agent`, `## CC Doc`, `## CC Rules`) are stripped from the output
