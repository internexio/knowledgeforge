# KnowledgeForge — Codex CLI

> **Experimental:** This target is under active testing. The current build installs a monolithic `AGENTS.md` and does not yet package the full Codex skills, hooks, subagents, MCP, and plugin surfaces.

Pre-compiled output for OpenAI Codex CLI. Generated by `compiler/kf-compile.py --target codex`.

## Install

Install into one project:

```bash
bash install.sh --codex --project /path/to/your/project
```

Or install globally for all local Codex projects:

```bash
bash install.sh --codex --global
```

The project command writes `/path/to/your/project/AGENTS.md`; the global command writes `~/.codex/AGENTS.md`. Codex loads the global instructions for every project, while a repository's `AGENTS.md` remains the appropriate choice when a project needs its own rules.

The installer will not replace different existing instructions unless you provide `--force`; that option saves a timestamped `.knowledgeforge-backup-*` copy first. Add `--dry-run` to either command to preview it without changing files.

## Update Flow

When modules in `knowledgeforge-core` change:

```bash
cd ~/Scripts/knowledgeforge-core
python3 compiler/kf-compile.py --target codex --output platforms/codex
```

Then re-run the appropriate installation command:

```bash
# Refresh the global installation
bash install.sh --codex --global

# Refresh one project installation
bash install.sh --codex --project /path/to/your/project
```
